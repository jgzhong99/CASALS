# Data and Output Layout

Local inputs and generated products are excluded from Git. Preserve original CASALS and 3DEP source files; workflow runs write beneath `outputs/`.

| Path | Contents | Handling |
| --- | --- | --- |
| `data/raw/casals_l1b/` | Original CASALS L1B H5 granules | Read-only source inputs. |
| `data/raw/tdms/` | TDMS recordings, `.tdms_index` sidecars, viewer assets, and notes | Original TDMS files are read-only. Index sidecars are not complete data files. |
| `data/reference/3dep/` | 3DEP LAS/LAZ clips | External reference data with source metadata. |
| `data/derived/` | Products intentionally reused as inputs | Record the source workflow before reuse. |
| `outputs/refh/<h5-stem>/` | Refh export, filtering, DSM, ground, classification, and evaluation products | Regenerable, per-input workflow outputs. |
| `outputs/peaks/<h5-stem>/` | Component, pulse, sweep, candidate-position, and validation products | Regenerable waveform analyses; secondary peaks are not official returns. |
| `outputs/reference/<h5-stem>/` | 3DEP download, diagnosis, and transfer outputs | Comparison products; transferred labels remain pseudo-reference. |
| `outputs/notebooks/<topic>/<notebook>/<dataset>/` | New outputs from active topic-organized notebooks | Dataset-specific; source data are read-only and no historical output is copied into this tree. |
| `outputs/notebooks/<notebook>/method_improvement/<granule-stem>/` | Results from earlier numbered-notebook method-improvement runs | Preserved historical artifacts; current reruns use the topic-organized path above. |
| `outputs/notebooks/<notebook>/scientific_review/<granule-stem>/` | Artifacts from earlier notebook review runs | Preserved historical outputs; no move or rewrite during notebook reorganization. |
| `outputs/notebooks/05_forest_transect_showcase/method_improvement/<granule-stem>/` | Candidate screening, dated NAIP crops, transect points/samples, figures, and selection metadata | Historical result root; existing products remain read-only inputs where referenced. |
| `outputs/notebooks/06_waveform_gallery/method_improvement/<granule-stem>/` | Six-pulse gallery, spatial evidence, small case/component records, and NAIP assets | Historical result root; selected waveform records only, no full waveform copies. |
| `outputs/notebooks/07_georeferencing_geometry/method_improvement/<granule-stem>/` | ENU geometry, field inventory, selected-pulse CSV, and manifests | Historical result root; H2 remains research mapping and closures are internal checks. |
| `outputs/notebooks/10_3dep_elevation_validation/` | H5/LAZ frame audit, AOI operation/grid availability, correction analysis, and reports | Historical validation inputs; absolute residuals remain bounded by the documented reference-frame gates. |
| `outputs/notebooks/11_landcover_lidar_response/` | Two-granule ROI populations, pulse manifests, waveform features, summaries, and figures | Historical validation outputs; image and membership inputs are read-only. |
| `outputs/notebooks/08_waveform_decomposition/method_improvement/<granule-stem>/` | Six-record TX/RX morphology fits, fit-window/K-cap diagnostics, residuals, and controls | Historical result root; Gaussian terms are unvalidated components and no TX/RX time alignment is asserted. |
| `outputs/notebooks/09_nadir_window_reflection/method_improvement/<granule-stem>/` | Bounded sweep diagnostics and waveform review artifacts | Historical result root; anomaly screening only, no real RX masking or subtraction. |
| `outputs/refactor_improvement_20261009/` | Results from the refactored classification, peak, and geolocation workflows | New-code validation outputs and diagnostics. |
| `backup/outputs/` | Historical runs moved out of the active output tree | Preserved local outputs from earlier code; ignored by Git. |
| `config/local/` | Workstation-specific GUI settings | Ignored by Git; do not publish. |

The source inventory records the original local H5, TDMS, reference, and baseline-output counts in [refactor_baseline.md](refactor_baseline.md). Original input data and all earlier notebooks remain preserved: 21 archived research notebooks plus four superseded root demos under `research/archived_notebooks/`. The 12 former numbered active notebooks were moved into five topic folders, and the active set now has 13 notebooks including the TDMS audit. Existing numbered output directories and metadata retain their original paths as historical results or read-only inputs; notebook code writes new results under the topic-organized layout above.

On 2026-10-09, prior results were gathered under `backup/outputs/` so the active `outputs/` tree contains only results generated by the current code and notebooks. The archived trees are `baseline_pre_refactor/`, `peaks/`, `refactor_validation/`, `refh/`, and `notebooks/h5_schema_audit/`. Their files were moved intact; metadata inside those historical runs retains its original creation-time paths. The move preserved 456 files (12,218,506,105 bytes); current outputs contain 80 files (1,133,580,222 bytes). The current notebook and new-code outputs are described in [refactor_improvement_report.md](refactor_improvement_report.md).

Both `outputs/` and `backup/` are ignored by Git. New CLI runs continue to write beneath `outputs/`; historical comparisons stay under `backup/outputs/`.
