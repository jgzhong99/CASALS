# Notebook Archive

This directory stores historical geolocation notebooks. The current
real-data entry points are under the repository's top-level `notebooks/`:

- `01_refh_quality.ipynb`
- `02_refh_classification.ipynb`
- `03_waveform_analysis.ipynb`
- `04_peak_geolocation.ipynb`

The current CLI geolocation implementation is `python -m casals_l1b peaks locate`;
read `docs/workflow_reference.md` and
`docs/refactor_improvement_report.md` for methods, validation, and limits.
Archived notebooks retain exploratory context and saved outputs; they are not
the active workflow entry points.
