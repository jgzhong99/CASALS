# Data and Output Layout

Local inputs and generated products are excluded from Git. Preserve original CASALS and 3DEP source files; workflow runs write beneath `outputs/`.

| Path | Contents | Handling |
| --- | --- | --- |
| `data/raw/casals_l1b/` | Original CASALS L1B H5 granules | Read-only source inputs. |
| `data/raw/tdms/` | TDMS recordings, index sidecars, viewer assets, and notes | Source/reference material. |
| `data/reference/3dep/` | 3DEP LAS/LAZ clips | External reference data with source metadata. |
| `data/derived/` | Products intentionally reused as inputs | Record the source workflow before reuse. |
| `outputs/refh/<h5-stem>/` | Refh export, filtering, DSM, ground, classification, and evaluation products | Regenerable, per-input workflow outputs. |
| `outputs/peaks/<h5-stem>/` | Component, pulse, sweep, candidate-position, and validation products | Regenerable waveform analyses; secondary peaks are not official returns. |
| `outputs/reference/<h5-stem>/` | 3DEP download, diagnosis, and transfer outputs | Comparison products; transferred labels remain pseudo-reference. |
| `outputs/notebooks/<notebook>/method_improvement/<granule-stem>/` | New outputs from the 2026-10-11 notebook method-improvement review | Isolated per notebook; source inputs and all earlier output folders remain read-only. |
| `outputs/notebooks/<notebook>/scientific_review/<granule-stem>/` | Artifacts from earlier notebook review runs | Preserved as historical outputs; do not overwrite when rerunning the current review. |
| `outputs/notebooks/05_forest_transect_showcase/method_improvement/<granule-stem>/` | Candidate screening, dated NAIP crops, transect points/samples, figures and selection metadata | Observed vs filled DSM distinguished; pre-existing source products remain read-only. |
| `outputs/notebooks/06_waveform_gallery/method_improvement/<granule-stem>/` | Six-pulse gallery, spatial evidence, small case/component records | Selected waveform records only; reused NAIP tiles retain source provenance; no full waveform copies. |
| `outputs/notebooks/07_georeferencing_geometry/method_improvement/<granule-stem>/` | Actual ENU geometry PNGs, standalone HTML, field inventory, selected-pulse CSV and manifest | H2 is research mapping; closures are internal consistency checks. |
| `outputs/notebooks/10_3dep_elevation_validation/` | Read-only H5/LAZ frame audit, AOI operation/grid availability and strict readiness figure | Absolute elevation residuals are not computed while reference-frame gates are blocked. |
| `outputs/notebooks/11_landcover_lidar_response/multi_granule_full_roi/` | Two-granule image-backed ROI population, full pulse manifest, waveform features, per-ROI/per-track summaries and figures | All nominal-center pulses are retained; 3-sigma is descriptive and ROI pulses are spatially dependent. |
| `outputs/notebooks/08_waveform_decomposition/method_improvement/<granule-stem>/` | Six-record TX/RX morphology fits, fit-window/K-cap diagnostics, residuals and synthetic controls | Gaussian terms are unvalidated waveform components; no TX/RX time alignment is asserted. |
| `outputs/notebooks/09_nadir_window_reflection/method_improvement/<granule-stem>/` | Preserved 90-sweep baseline, one large 180-sweep signed heatmap centered at zero, six all-bin follow-up blocks, event review and synthetic controls | Anomaly screening only; no real RX masking, subtraction, or modification without supported evidence. |
| `outputs/refactor_improvement_20261009/` | Results from the refactored classification, peak, and geolocation workflows | New-code validation outputs and diagnostics. |
| `backup/outputs/` | Historical runs moved out of the active output tree | Preserved local outputs from earlier code; ignored by Git. |
| `config/local/` | Workstation-specific GUI settings | Ignored by Git; do not publish. |

The source inventory records the original local H5, TDMS, reference, and baseline-output counts in [refactor_baseline.md](refactor_baseline.md). Original input data and all earlier notebooks remain preserved: 21 archived research notebooks plus four superseded root demos under `research/archived_notebooks/`. Twelve current notebooks, numbered 00 through 11, are under `notebooks/`; `.compile_tmp/` is an ignored local scratch directory used for execution and visual checks.

On 2026-10-09, prior results were gathered under `backup/outputs/` so the active `outputs/` tree contains only results generated by the current code and notebooks. The archived trees are `baseline_pre_refactor/`, `peaks/`, `refactor_validation/`, `refh/`, and `notebooks/h5_schema_audit/`. Their files were moved intact; metadata inside those historical runs retains its original creation-time paths. The move preserved 456 files (12,218,506,105 bytes); current outputs contain 80 files (1,133,580,222 bytes). The current notebook and new-code outputs are described in [refactor_improvement_report.md](refactor_improvement_report.md).

Both `outputs/` and `backup/` are ignored by Git. New CLI runs continue to write beneath `outputs/`; historical comparisons stay under `backup/outputs/`.
