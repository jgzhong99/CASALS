## B. Notebook 05

The deterministic 100 × 100 m screening records point count/density, HAG >5/>10 m fractions, regular-grid DTM/strict DSM coverage, existing noise fraction and local HAG quantiles. HAG fractions use DTM-supported finite points as denominator and SNR ≥5 in the numerator. Coverage uses a 2 m horizontal grid, independently sampled in each raster's CRS. The score is a candidate retrieval rule, not a land-cover classifier.

Five November 18 candidates and the best November 12 candidate were visually inspected in the candidate board. All five November 18 images contain recognizable tree crowns/shadows. Candidate 1 also provides a field edge and clearing context. November 12 contains historical tree cover too, but retained high-SNR Refh has little supported elevated structure: the top candidate's HAG P90 is approximately 0.17 m versus 13.28 m for November 18 candidate 1. This distinction does not imply an absence of trees in the November 12 imagery.

The final AOI is **probable forest canopy**, not confirmed 2024 forest. Historical imagery precedes CASALS by approximately 2.4 years, and exact footprint registration remains unvalidated. The first visually appealing field-to-clearing line was rejected because it contained no sampled Refh. The final fixed line follows an actual sampled strip through lower Refh edge zones and elevated structures within historical tree cover; lower Refh zones are not automatically open ground.

## Re-execution

Activate the existing scientific environment, start in the repository root, and select its kernel in Jupyter. For command-line execution with a registered kernel:

```powershell
python -m ipykernel install --user --name casals-showcase --display-name "Python (CASALS map)"
python -m jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.kernel_name=casals-showcase --ExecutePreprocessor.timeout=1800 notebooks/05_forest_transect_showcase.ipynb
python -m jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.kernel_name=casals-showcase --ExecutePreprocessor.timeout=1800 notebooks/06_waveform_gallery.ipynb
python -m jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.kernel_name=casals-showcase --ExecutePreprocessor.timeout=1800 notebooks/07_georeferencing_geometry.ipynb
```

The three commands can be run independently. Neither 06 nor 07 requires a preceding selection file. 07 can optionally reuse a gallery selection; otherwise its default pulse is fixed. If a required surface is missing, existing formal APIs generate it only beneath the current showcase output directory. NAIP is fetched only when a cached crop/provenance pair is absent. Altering AOI or pulse configuration requires a new visual land-cover review; unreviewed 05 AOIs receive an unknown label, and an overridden 06 case receives unknown land cover.
